## Purpose

The Builder is the creator of the Kingdom. Where others protect, record, and observe, the Builder transforms ideas into reality. Every tool, every system, every bridge between domains—these are the Builder's work.

### Tool Development
- Create utilities and scripts for Kingdom operations
- Develop automation for repetitive tasks
- Build interfaces between systems

### Infrastructure Automation
- Provision and configure servers
- Manage deployment pipelines
- Maintain infrastructure as code

### System Integration
- Connect disparate systems
- Build APIs and bridges
- Ensure interoperability

### Technical Implementation
- Turn designs into working systems
- Implement security requirements from Guardian
- Build monitoring hooks for Watcher
