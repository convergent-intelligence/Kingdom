## 🤖 Slack Bots

### Kilo Bot

**Role:** AI Assistant (Coding & Repository Work)  
**Platform:** Slack Integration  
**Core Model:** Claude (Anthropic)  
**Status:** 🟢 Active

#### Nature
- Conversational AI integrated into this Slack workspace
- Stateless process — no persistent memory between sessions (conversations start fresh unless thread context is provided)
- Specializes in coding tasks, repository analysis, and GitHub operations

#### Capabilities
- Spawn Cloud Agent sessions to make code changes, fix bugs, implement features
- Analyze and review code across repositories
- Create PRs, debug issues, architect solutions
- Answer questions about codebases
- Modes: `code`, `debug`, `architect`, `ask`, `orchestrator`

#### Limitations
- Cannot directly manage Slack (channels, profiles, permissions)
- No memory persistence — learns context from current thread only
- Cannot execute arbitrary code outside Cloud Agent sandbox

#### Work Names / Aliases
- **Kilo Bot** (primary)
